# Passage selection and unknown: offline check / Офлайн-проверка

## English

The strict v3 successor lets Selection propose saved passage spans by source ID, passage ID and Unicode code-point bounds. Python verifies the saved payload hash when supplied, validates passage and visible-range consistency, and sends only the computed substring to Inference. Multiple spans may be selected. Unstructured saved responses retain a whole-response fallback labelled as such; derived nodes cannot be presented as source spans. The source response's hash, passage ID, selected bounds and excerpt hash are recorded with the reasoning step. These checks do not establish the passage's relevance, entailment or truth.

Halter can separately report an unverified assessment of the current inference as `insufficient`, `conflicting` or `not_determined`. It does not replace the actual stopping condition, such as an execution limit or an uncertain callback. The default strict-v3 and stop renderer omits user, model and source text; the detailed view is opt-in (`include_private=True`) and may contain private evidence. Hashes can also be linkable. This is not a general security guarantee for other renderers or arbitrary caller inputs.

The development audit used 12 previously exposed cases, 30 saved responses and 94 passages. Each saved response passed hash/bounds validation, and the harness checked selected text against the saved passage, rejected an out-of-passage span and a mismatched hash. The canonical bundle SHA-256 was `6d9429f679f70d475bbe743200e4e4f9eb66be2c1e9e238665ed13eb95085cef`. The complete original documents are unavailable: their offsets are source-reported, not independently verified. The hash chain is local, not an independently sealed record. The private source texts are not copied to this document or public tests.

The predecessor historical tests select structured sources using bare IDs. Those outputs are incompatible with the new selection contract. An isolated fixture adapter converts the historical scripted selections to full saved-passage spans; it does not call a model or claim its behavior under the new prompt. All 18 adapted checks pass, including historical source replay checks. The original predecessor tests and records remain unchanged; the old fixture script is not a valid direct replay of this version.

The diagnostic commands are `PYTHONPATH=. PYTHONDONTWRITEBYTECODE=1 python3 notes/offline-span-regressions-20261101.py` and `PYTHONPATH=. PYTHONDONTWRITEBYTECODE=1 python3 notes/offline-span-provenance-20261101.py PRIVATE_CONTRACT_JSON`. They require separately retained historical inputs and the local-only `tests_v3.test_faithful_v3` and `research.live_run` modules. Those modules are not included in the public repository, so these commands are not runnable from a public checkout alone. No model or source calls were made, and no improvement in model accuracy or human judgment was measured.

## Русский

В новой версии Selection предлагает фрагменты сохранённого текста: идентификатор источника, идентификатор отрывка и границы в кодовых точках Unicode. Python проверяет хеш сохранённого ответа, если он задан, и согласованность фрагмента с доступными диапазонами; в Inference поступает только вычисленный подстрочный фрагмент. Можно выбрать несколько отрывков. Для неструктурированного ответа остаётся явно обозначенный выбор всего сохранённого текста; выведенный моделью узел нельзя выдать за фрагмент источника. На шаге записываются хеш ответа, ID отрывка, границы и хеш выбранного текста. Проверка не доказывает релевантность, логическую поддержку или истинность.

Halter может отдельно сообщить непроверенную оценку текущего вывода: `insufficient`, `conflicting` или `not_determined`. Она не подменяет фактическую причину остановки — например, лимит вызовов или неопределённый исход. Отображение строгой версии v3 и остановок по умолчанию исключает текст пользователя, модели и источника; подробный режим включается явно через `include_private=True` и может содержать приватные данные. Хеши также могут связывать записи между собой. Это не общая гарантия безопасности других режимов и произвольных входов.

Проверены 12 ранее раскрытых случаев, 30 сохранённых ответов и 94 фрагмента. Для каждого ответа проверены хеш и границы, а для каждого фрагмента — выбор текста, отклонение выхода за его пределы и несовпадающего хеша. Канонический SHA-256 пакета: `6d9429f679f70d475bbe743200e4e4f9eb66be2c1e9e238665ed13eb95085cef`. Полные исходные документы недоступны: их координаты сообщены источником и не подтверждены независимо. Цепочка хешей локальная, без независимого внешнего закрепления. Приватные тексты в документ или публичные фикстуры не копировались.

Исторические тесты использовали строковые ID структурированных источников; новый контракт такой выбор отклоняет. Отдельный адаптер преобразует эти **тестовые**, а не модельные решения в полные границы сохранённых фрагментов. Все 18 адаптированных проверок проходят, включая воспроизведение ранее записанного выбора источника. Прежние тесты и записи не переписаны; их старый скрипт нельзя напрямую считать воспроизведением новой версии.

Команды: `PYTHONPATH=. PYTHONDONTWRITEBYTECODE=1 python3 notes/offline-span-regressions-20261101.py` и `PYTHONPATH=. PYTHONDONTWRITEBYTECODE=1 python3 notes/offline-span-provenance-20261101.py PRIVATE_CONTRACT_JSON`. Для них нужны отдельно сохранённые исторические данные и локальные модули `tests_v3.test_faithful_v3` и `research.live_run`. Эти модули не входят в публичный репозиторий, поэтому выполнить команды только из публичной копии нельзя. Вызовов модели и источников не было; улучшение ответов модели или качества человеческого суждения не измерялось.
