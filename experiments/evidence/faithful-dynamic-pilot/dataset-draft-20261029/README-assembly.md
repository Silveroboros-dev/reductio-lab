# Offline assembly: eight cases and pending paid evidence

`assemble.py` builds `assembled-v1/` from `draft.json`, the exact user-relayed targeted snapshot, its reported receipt, the full active FitCheck pair-label guide, the recorded six-wording human acceptance, and individually bound original lines from the two historical advisory normalization decisions and packets. It copies supporting bytes to a new 0700 private directory and never edits source, governed review files, an existing output or a provider.

The output intentionally uses `faithful-dynamic-draft-manifest-v1`, not the runner's admissible `faithful-dynamic-pilot-manifest-v1`. Its task projection includes only the manual rule replay, while each case separately contains the fixed pre-acquisition news request and unresolved expected gap. All paid-source prices and responses are missing. This prevents falsely declaring the experiment ready or silently running a manual-only substitute. The six `test` rows are diagnostic candidates; the designation is not evidence of semantic novelty or an unexposed holdout.

Each included evidence item is one full JSON leaf (or the complete text of the guide) bound to its attachment hash; market and event identities, accepted thesis text, source rules and the two historical human-decision line hashes are checked. Human acceptance is scoped to conditional thesis wording and is not a forecast or adjudication. The copied manual capture records the user's report of Grok's direct request, not independent verification of provider transport. Original conflicting Fed fields are retained with `unresolved` status; no official-page wording is silently substituted. Empty secondary rules do not prove complete resolution terms.

## Pending inputs and create-only successor

For each of eight predeclared queries, a separately authorized actual source capture must provide: exact request bytes and response; provider/endpoint and UTC times; account-specific whole-request price evidence and expiry; operation ID and a settled shared-ledger receipt; raw response SHA-256; and a provenance-bound, verbatim extracted evidence leaf. Source acquisition must respect the user-approved operation and dollar limits. A missing, dynamic or expired quote and an uncertain call block the affected operation. Provider output is untrusted data and never adds authorization or an adjudicated label.

After capture, create a **new** successor bundle, reusing the exact thesis, identities, manual replay, source and acceptance bindings from `assembled-v1`; append only the predeclared paid action, pinned quote and corresponding actual response evidence to each runnable case. Recompute and bind successor case/manifest hashes, preserve this predecessor and perform a separate pre-execution review. Changed serialized case bytes in a new version do not mean changing or re-approving the original wording; do not mutate the existing files. No independent human semantic adjudication or pristine holdout is implied.

The original draft's queries were written before any Orthogonal news source capture, but the SHA chain remains inside the same local mutable workspace; it is not an externally sealed timestamp or independent proof of blindness.
