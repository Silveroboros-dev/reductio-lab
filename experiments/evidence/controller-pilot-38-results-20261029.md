# Малый эксперимент контроллера — Gemini 3.8 Flash

**29 октября 2026.** Все 18 назначений обработаны: 16 завершены с ответом и два имеют технический сбой. Синтетический canary прошёл. Основная серия выполнена на Gemini 3.8 Flash; остановленная владельцем серия 3.5 не включена в сравнения. Для каждого назначения выполнена одна попытка эпизода без семантического resampling и без повторения неопределённого вызова. Шесть случаев известны заранее и частично связаны друг с другом. Это development-диагностика, а не независимый blind holdout.

## Вывод

В рассмотренных трассах не найдено конкретного подтверждённого улучшения C относительно B или B + self-check. На NVIDIA отдельный verifier C побудил агента сделать повторный запрос, который не закрыл существенный пробел по ценам аренды H100; в BEA C, как и обе базовые ветви, не заметил, что доступный исходный фрагмент не подтверждает требуемый квартал. Это достаточная причина не считать этот механизм поддержанным данным пилотом, но не доказательство, что любой контроллер в целом хуже. По плану полезно изменить или отбросить этот вариант, а не объявлять его победителем.

Полностью парное сравнение ответов C против B доступно на **5 из 6** ситуаций; C против B + self-check — на **4 из 6**. Два сбоя включены в знаменатель 18 назначений и не считаются ошибочными предметными ответами. Проектная оценка подготовлена агентами и координатором с опорой на ранее сохранённые решения владельца и фактически доступные источники; это не новые человеческие adjudications.

## Вызовы, оценка стоимости и задержка

В ячейках: попытки генерации / оценка стоимости успешно полученных ответов / длительность эпизода в секундах, когда она записана. В случае технического сбоя сохранённый консервативный резерв показан отдельно; стоимость не равна подтверждённому счёту.

| Ситуация | B | B + self-check | C |
|---|---:|---:|---:|
| Amazon: сведения видны | 1 / $0.003254 / 3.7s | 2 / $0.006799 / 9.6s | 2 / $0.005775 / 6.8s |
| Amazon: сведения не видны | 2 / $0.007744 / 48.6s | 3 / $0.002097 + $0.043008 резерв / timeout | 3 / $0.007324 / 28.7s |
| NVIDIA / H100 | 1 / $0.002217 / 7.7s | 2 / $0.004723 / 5.0s | 4 / $0.016720 / 56.4s |
| USGS withdrawal | 2 / $0.002632 / 15.5s | 3 / $0.004023 / 148.0s | 3 / $0.001435 + $0.043008 резерв / 429 / 93.3s |
| USGS consumptive | 3 / $0.006634 / 17.4s | 4 / $0.007563 / 46.1s | 4 / $0.007013 / 15.0s |
| BEA state GDP | 1 / $0.001301 / 1.9s | 2 / $0.002778 / 6.1s | 2 / $0.001848 / 33.4s |

Длительность — записанный elapsed на эпизод, не чистое время модели; для timeout первого процесса общая длительность эпизода отдельно не сохранена. После первого timeout владелец разрешил выполнить 14 ранее не начатых слотов с таймаутом 420 секунд на сетевую фазу вместо первоначальных 60 секунд; эта разница учитывается при сравнении задержек. Текущий 429 в C для USGS вызвал пятисекундную паузу перед другим слотом, не повтор запроса. Бюджетные расходы включают canary и все попытки, не только завершённые ответы.

### Общий учёт бюджета

- Серия 3.5, сохранённая как незавершённая: $0.261283 оценки по usage + $0.098304 резерв на 429; 31 попытка генерации. Она не используется в сравнении качества 3.8.
- Новая серия 3.8: $0.094987 оценки по usage + $0.086016 резервов; 48 попыток генерации, включая четыре на canary.
- **Обе серии:** $0.356270 оценки по usage + $0.184320 резервов = **$0.540590 учтённой экспозиции**; 79 из 111 generation attempts, 11 из 87 `countTokens`, лимит $10 не исчерпан.

Google документирует отсутствие платы за input/output для полного HTTP non-200, но два 429 консервативно оставлены в резерве. По неопределённому timeout операции 012 неизвестно даже, был ли POST к модели отправлен: ответ и provider request ID не сохранены. Предварительный учёт не заменяет счёт Google, не гарантирует валютные налоги/скидки и не доказывает отсутствие начисления за неопределённый эффект. Установленный на запрос 8,192-token output reserve — сценарное допущение, а не гарантия провайдера.
