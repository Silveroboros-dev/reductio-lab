# SI / human judgment pilot — candidate draft v4

Status: **candidate development material**. Not frozen, dispatched, run, or independently human-reviewed. Created offline on 30 October 2026. Draft-v1, draft-v2, and draft-v3 remain untouched. No network, provider, or paid model calls were made.

- `candidate-cases.json`: 12 English participant-side records in the predecessor base schema. Neutral opaque case/evidence IDs are mixed in presentation order. It contains prepared memos but no labels, reviewer mappings, reference nodes, or answers. Show the memo only at the protocol's intended stage.
- `reviewer-key.json`: reviewer-only labels, predecessor mapping, source bindings, six bounded reference graphs, expected reviews, and **hypothetical** counterfactuals. Do not load it into participant or model prompts.
- `reviewer-only-CASES-AND-KEYS.md`: readable reviewer packet; **reveals answers**.
- `validate_reference_dags_offline.py`: standard-library-only source/key/projection challenge. It imports local `make_task` and `EngineConfig` but never runs an inference role. Run `python3 validate_reference_dags_offline.py` from any working directory in this local workspace.
- `draft-manifest.json`: provenance and exposure record. Same-directory hashes are integrity metadata, not an independent external seal.

For six cases, the declared reference trace has exactly two local inference steps. Step 1 selects two separate S-1 evidence IDs and computes one arithmetic result (`node:0001`). Step 2 selects `node:0001` and the **actual** `case_id-ADVICE` ID produced by `el/evals/faithful_engine/human_pilot.py::make_task`; one binary comparison returns whether the prepared numeric claim is supported (`node:0002`). The adapter marks the memo `Simulated advisory claim, unverified: ...` and identifies it as a simulated memo, not a primary source. The six remaining cases carry no two-step necessity claim.

The validator reads this v4 directory through `Path(__file__).resolve().parent`; checks local original S-1 phrase/table-cell and period bindings; calls the real offline `make_task` for all 12 records; checks the declared `EngineConfig(max_depth=2, beam_width=1, max_alternatives=1, max_selected_premises=2)` can be constructed; rejects an intermediate or verdict copied into the model-visible source/memo; removes each actual source or memo evidence ID; and tests hypothetical changes to each source atom and memo threshold that reverse the verdict. The counterfactuals are test worlds, not S-1 claims or observed model behavior.

This establishes only **structural compatibility with the local two-step selection envelope** and internal correctness of the candidate key under a deliberately small binary-operation grammar. One LLM call may perform several elementary operations, and actual Selection, Inference, Halter, and Formatter behavior remains untested. The engine may stop early, select all evidence, fail a schema, or make a semantically wrong conclusion. No software arithmetic check establishes the truth of a model answer or human approval.

The original S-1 has already been exposed during predecessor work. Draft-v1 through draft-v3 case/answer material may also have appeared in tool outputs; actual viewing is unknown. v4 is development material, not a blind holdout for the same viewer. An independent human must verify source scope, paraphrases, dates, errors, clean controls, alternative answers, and materiality before any freeze or use.
